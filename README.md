## 🧠 Core Architecture & Tools Used
This portfolio was architected using an AI-assisted engineering approach, focusing on UI/UX optimization and high-performance rendering.
* **Frontend:** React, Tailwind CSS
* **Animations:** Framer Motion (Digital materialization, scroll reveals, milestone tracking)
* **Media Optimization:** Canva & CapCut (Pre-rendered complex system diagrams to offload heavy DOM rendering)
* **Hosting/Deployment:** Vercel

## ⚙️ Key Features
* **Cinematic Dual-Pane UI:** A locked left-side avatar ("Silicon Jack") paired with a scrolling narrative right pane.
* **Milestone Map Navigation:** Horizontal timeline navigation for seamless chapter jumping.
* **STAR Methodology Modals:** Technical case studies (Situation, Task, Action, Result) for key projects:
  * Multi-layer FPGA PCB Design (KiCad)
  * Edge AI / TinyML Vehicle Detection
  * Vihang Radar (n8n & Gemini API Automation)
