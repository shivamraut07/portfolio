# Silicon Jack - Avatar Assets

This directory contains the character posture renders for the Silicon Jack portfolio. The application dynamically loads these images based on the active chapter index.

## File Mapping

| Filename | Posture / Vibe | Portfolio Chapter Assignment |
| :--- | :--- | :--- |
| `SJ00.png` | Arms Crossed (Confident) | Chapter 00 - Opening / Intro |
| `SJ01.png` | Pointing Up (Idea/Foundation) | Chapter 01 - The Foundation |
| `SJ02.png` | Holding PCB | Chapter 02 - Embedded Systems & Hardware |
| `SJ03.png` | Holding Tablet | Chapter 03 - Edge AI / TinyML |
| `SJ04.png` | Presenting / Hand Out | Chapter 04 - Systems Integration |
| `SJ05.png` | Hologram UI Panels | Chapter 05 - Software / Architecture |
| `SJ06.png` | Desk / Multi-Monitor | Chapter 06 - Workflow / Setup |
| `SJ07.png` | Thumbs Up | Chapter 07 - Contact / Resume |

**Usage Note:** Ensure all files maintain `.png` extension and transparent backgrounds. If updating a pose, simply overwrite the corresponding `SJ0X.png` file without changing the code.
